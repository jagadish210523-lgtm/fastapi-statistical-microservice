# FastAPI Statistical Microservice 🚀

A lightweight, high-performance microservice built from scratch using **FastAPI** and **Pydantic v2**. This service processes numerical datasets and computes core statistical dispersion metrics without relying on heavy external data science libraries.

## 📌 Features
* **Robust Data Validation:** Utilizes Pydantic to enforce data structures, minimum length constraints, and types.
* **Pure Python Statistics:** Computes mean, variance, and standard deviation using native Python and generator expressions.
* **Clean API Design:** Exposes a structured POST endpoint returning formatted JSON output.

---

## 🛠️ Tech Stack
* **Python**
* **FastAPI** (Web Framework)
* **Pydantic v2** (Data Validation)
* **Swagger UI**
